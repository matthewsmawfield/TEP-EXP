# TEP-EXP Scripts

Paper 9 (Istanbul) is a conceptual and measurement taxonomy paper formalizing gauge-invariant versus convention-dependent observables in precision tests of General Relativity. It does not run an empirical data analysis pipeline.

- `generate_site_pdf.py`: Generates the manuscript PDF from `site/dist/index.html`.
- `utils/process_pdf.py`: Compresses and embeds publication metadata into the generated PDF.
